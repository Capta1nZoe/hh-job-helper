# HH Job Helper

Личный прототип Windows-приложения для поиска вакансий на hh.ru.

## Запуск

1. Установите Python 3.10 или новее для Windows с https://www.python.org/downloads/windows/.
2. Откройте PowerShell в папке проекта.
3. Запустите `py outputs/hh_job_helper.py`.

Приложение использует стандартную библиотеку Python и не требует установки пакетов. Публичный поиск hh.ru работает без OAuth. Для запроса к API передаётся User-Agent.

## Что уже есть

- Поиск вакансий по ключевым словам, городу и минимальной зарплате.
- Фильтр удалённого формата.
- Обновление по выбранному интервалу, пока приложение открыто.
- Сохранение фильтров в `%LOCALAPPDATA%\HHJobHelper\settings.json`.
- Открытие выбранной вакансии на hh.ru двойным щелчком.
- Локальные поля для учётных данных Telegram и OAuth hh.ru. Секреты хранятся в Windows Credential Manager.
- Подключение Telegram: после сохранения токена нажмите в боте `/start`, затем в приложении — «Подключить / проверить Telegram». Приложение проверит бота, найдёт ваш чат и отправит тестовое сообщение.
- Уведомления о новых вакансиях отправляются в Telegram после первого цикла поиска.
- После OAuth можно загрузить список своих резюме из `/resumes/mine`; в прототипе автоматически выбирается первое резюме.
- В текстовых полях работают Ctrl+V и контекстное меню по правому щелчку.

## Безопасность и ограничения

Поле OAuth пока служит только для локального хранения реквизитов; вход hh.ru через OAuth не подключён. Автоматические отклики не реализованы.

## Пока не реализовано

- Telegram-уведомления: нужны токен бота и подключение отправки сообщений.
- OAuth-вход hh.ru и анализ резюме.
- Автоматические отклики: доступность метода для соискателя необходимо подтвердить; приложение пока не отправляет отклики.
- Сопоставление гибридного формата и полноценный балл соответствия резюме.
